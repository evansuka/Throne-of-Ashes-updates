# Commandes de triche — Solo

Dans une partie solo, ouvre le chat avec Entrée, sélectionne **Système**, saisis la commande puis Entrée. `/help` affiche l’aide. Identifiants ci-dessous ou noms complets acceptés ; accents, espaces et tirets ignorés. Aucune commande en multijoueur. Les objets vont au coffre si le sac est plein.

| Commande | Objet unique |
|---|---|
| `/get sovereign-horn` | Corne du Souverain des Cendres |
| `/get promise-of-aelis` | La Promesse d’Aélis |
| `/get oathbreaker` | Brise-Serment |
| `/get dawn-of-the-just` | Aube des Justes |
| `/get thorn-widow` | Veuve des Ronces |
| `/get storm-heart` | Cœur de Tempête |
| `/get revenant-steps` | Pas du Revenant |
| `/get velydra-tear` | Larme de Velydra |
| `/get last-oath-seal` | Sceau du Dernier Serment |
| `/get sovereigns-heart` | Cœur du Nouveau Souverain |
| `/get unbound-ember` | Éclat du Cycle Brisé |

| Commande | Portail à Havrebrume |
|---|---|
| `/portal tharok` | Tharok, le Roi Brisé, étage 20 |
| `/portal velyra` | Velyra, la Reine des Venins, étage 40 |
| `/portal ilyss` | Ilyss, l’Oracle Foudroyant, étage 60 |
| `/portal mordrath` | Mordrath, le Seigneur des Flammes, étage 80 |
| `/portal azhrael` | Azhraël, le Dernier Gardien, étage 100 |

Les portails débloquent l’accès sans tuer les boss ni terminer les quêtes. Les trois charmes de fin ne cumulent pas leurs bonus entre eux : la règle d’un seul charme de destinée actif est conservée. La Corne reste absente du butin normal ; sa commande est une exception de triche explicite. Les donjons se réinitialisent lors d’une nouvelle session, les objets et portails sont conservés.
